# class: HarmonyOSWebView
* since: v1.50

HarmonyOSWebView represents a webview on a HarmonyOS device.

## method: HarmonyOSWebView.socketName
* since: v1.50
- returns: <[string]>

Returns the socket name for connecting to DevTools.

## method: HarmonyOSWebView.package
* since: v1.50
- returns: <[string]>

Returns the package name of the webview.

## method: HarmonyOSWebView.title
* since: v1.50
- returns: <[string]>

Returns the title of the webview.

## method: HarmonyOSWebView.url
* since: v1.50
- returns: <[string]>

Returns the current URL of the webview.
